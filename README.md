# Analisador de Palavras em Java

Projeto desenvolvido em Java com foco em lógica de programação, estruturas de repetição e manipulação de `String`.

O sistema funciona pelo terminal e permite que o usuário analise palavras por meio de um menu interativo.

## Funcionalidades

- Contar vogais de uma palavra
- Contar consoantes de uma palavra
- Inverter uma palavra
- Validar opções do menu
- Encerrar o programa pelo terminal

## Tecnologias utilizadas

- Java
- Scanner
- Estruturas de repetição
- Condicionais
- Manipulação de Strings

## Conceitos praticados

Durante o desenvolvimento, foram praticados conceitos fundamentais da linguagem Java, como:

- `while`
- `for`
- `if` / `else if`
- `Scanner`
- `String`
- `charAt()`
- `length()`
- `toLowerCase()`
- `Character.isLetter()`
